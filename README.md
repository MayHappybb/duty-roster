# D402 实验室值日表生成器

纯前端静态网页。填写**人员顺序**和**起止日期**，自动生成与原 Word 模板一致的每月值日表，可直接打印或另存为 PDF。

- 无需后端、无需安装依赖、无需构建
- 数据只保存在本机浏览器（localStorage），不会上传
- 支持配置导出 / 导入（JSON）

## 使用

1. 打开 `index.html`（或部署后的网址）。
2. 在左侧填写表格标题、人员顺序、起止日期。
3. 右侧会实时生成每一页值日表。
4. 点击右上角 **打印 / 另存为 PDF**，在打印窗口中选择：
   - 目标：**另存为 PDF**
   - 纸张：**A4**
   - 方向：**纵向**
   - 边距：**默认**（页面已按 A4 排好版）

> 建议使用 Chrome / Edge 打印。Safari 也可以，但边距选项请保持“默认”。

## 排班规则

与原表保持一致：

- 每周一班，**周一至周日**，每人连续值班 7 天。
- 按“值班人员”列表顺序循环，跨月不重置。
- “排班起点”决定轮换从哪一周、由谁开始；修改人员顺序后，以起点周的值为基准继续循环。
- 左侧日表固定 31 行。当月不存在的日期、以及起止范围之外的日期显示为 `\`。
- 右侧周表列出当月涉及的班次，最多 5 行（与原模板一致）。
- 若当月出现第 6 个班次（例如 31 天且从周六/周日开始），日表仍会显示该班次，周表按模板只列前 5 个。

首次打开时是一份占位名单。把左侧“值班人员”换成你们组的名单（每行一人）即可，浏览器会记住；也可以在“高级：调整排班起点”里指定起点周和该周的值日人。

默认起点周为 2026-10-26（周一）。如果换上的新名单里没有原来的起点值日人，程序会自动把新名单的第一位作为起点值日人。

## 配置 JSON

“导出配置”得到的文件格式如下，可通过“导入配置”恢复：

```json
{
  "title": "表1 机械与动力工程学院实验室卫生值日表(请贴于门后)",
  "people": ["值班人员1", "值班人员2", "值班人员3", "值班人员4", "值班人员5", "值班人员6", "值班人员7", "值班人员8", "值班人员9"],
  "start": "2026-11-01",
  "end": "2027-06-30",
  "anchorDate": "2026-10-26",
  "anchorPerson": "值班人员1"
}
```

- `anchorDate` 会自动对齐到所在周的周一。
- `anchorPerson` 必须是 `people` 中的一位。
- 配置同时会自动保存在浏览器本地，下次打开自动恢复。

## 部署到 GitHub Pages

```bash
cd ~/coding/duty-roster
git init
git add .
git commit -m "Add duty roster generator"
gh repo create duty-roster --public --source=. --remote=origin --push

# 开启 Pages（main 分支根目录）
gh api -X POST "repos/MayHappybb/duty-roster/pages" \
  -f "source[branch]=main" -f "source[path]=/"
```

稍等片刻，访问 `https://mayhappybb.github.io/duty-roster/`。

> 公开站点默认使用占位姓名，真实名单只保存在你自己的浏览器里（localStorage），不会上传到 GitHub。

## 字体说明

打印表格使用的字体（通过 `local()` 读取本机字体）：

| 用途 | Windows | macOS |
| --- | --- | --- |
| 表格正文 | 仿宋（FangSong） | STFangsong（仿宋） |
| 标题 | 黑体（SimHei） | Heiti SC（黑体） |

如果本机没有对应字体，会回退到宋体/系统无衬线字体，版式不变，字形会略有差异。要得到与原始 PDF 完全一致的字形，请在安装了「仿宋 / 黑体」的 Windows 上打印。
